## API surface — read this before assuming an integration exists

Parsyl DOES have an API, and it is NOT publicly documented.

- API documentation: https://docs.parsyl.com/ — Parsyl's own docs host, fronted by CloudFront
  and gated by an Amazon Cognito user pool named `parsyl-api-docs`. Every path, including
  `/.well-known/*` and `/openapi.json`, returns HTTP 302 to `/auth/login`, which starts an
  OAuth 2.0 Authorization Code + PKCE flow (scope `openid email profile`). You need a Parsyl
  account to read anything.
- A Parsyl-controlled API host exists at `https://api.parsyl.io` (AWS API Gateway, TLS cert
  CN=api.parsyl.io). It answers every anonymous request with HTTP 403
  `{"message":"Missing Authentication Token"}`. No public Parsyl document names it as the base
  URL, so API Evangelist has deliberately NOT recorded it as the API's baseURL.
- Integration is relationship-scoped: Parsyl describes "custom API integration" for customers,
  and a [Data Partner Program](https://www.parsyl.com/media/media/data-partner-program-launch)
  that ingests telemetry from Berlinger, Copeland (formerly Emerson), Roambee, Sensitech and
  Tive. The route in is a conversation, not a signup.

## Security and compliance

- Parsyl states it completes a [SOC 2 Type II examination](https://www.parsyl.com/media-old/soc2-type2-exam)
  annually, evaluated by a licensed CPA firm, and lists two-factor authentication, encryption,
  documented security policies and a security training program among its controls.
- No trust center, no vulnerability disclosure policy and no bug bounty program were found.
- Domain security as probed: HTTPS with TLS 1.3 and HSTS (max-age 31536000) on both
  www.parsyl.com and docs.parsyl.com; SPF and DMARC present on parsyl.com with policy
  `quarantine`; no DNSSEC and no CAA records.
